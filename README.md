## 📦 実装作品一覧

### 1. 10進数から2進数・8進数・16進数・n進数への基数変換プログラム
- **概要**: 入力された10進数整数を、任意の数（2進数 / 8進数 / 16進数など）へ変換して出力するプログラム。
- **実装の工夫・学習ポイント**:
  - 標準ライブラリに頼らず、剰余演算（%）と除算（/）を用いた基数変換アルゴリズムを自力実装。
  - 配列と `while` ループを活用し、算出されたビット列を逆順で出力するロジックを構築。
  - マジックナンバーを排除し、定数（`const int`）を用いた安全な配列サイズの管理と初期化を適用。
	
### 2. 2進数・8進数・16進数・n進数から10進数への基数変換プログラム
- **概要**:　入力された任意の進数の整数（2進数 / 8進数 / 16進数など)を10進数へ変換して出力するプログラム。
- **実装の工夫・学習ポイント**:
  - 標準ライブラリに頼らずホーナー法を用いた基数変換アルゴリズムを自力実装。
  - マジックナンバーを減らし拡張性の維持。
  - 入力を文字にすることでアルファベットの文字に対応。計算の時に文字コードでの計算を実装。
  - 大文字・小文字の両対応に加え、指定進数以外の文字が入力されたときにエラーメッセージが表示される入力チェックを実装。
