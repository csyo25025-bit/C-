### 1. 10進数から2進数・8進数への基数変換プログラム
- **概要**: 入力された10進数整数を、指定した基数（2進数 / 8進数）へ変換して出力するプログラム。
- **実装の工夫・学習ポイント**:
  - 標準ライブラリに頼らず、剰余演算（%）と除算（/）を用いた基数変換アルゴリズムを自力実装。
  - 配列と `while` ループを活用し、算出されたビット列を逆順で出力するロジックを構築。
  - マジックナンバーを排除し、定数（`const int`）を用いた安全な配列サイズの管理と初期化を適用。
